02 / GET STARTED

Human hands
or agent hands.

Both routes install the same checksum-verified binary. Pick the amount of typing you feel like doing.

Install it yourself

macOS and Linux install to ~/.local/bin. Windows gets a PowerShell installer.

curl -fsSL https://raw.githubusercontent.com/gabrielchantayan/paper/main/install.sh | sh
paper init
paper agent install all
